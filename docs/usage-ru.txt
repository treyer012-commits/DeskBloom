DESK BLOOM 4.1.1 — группы на обычном рабочем столе Windows

Один рабочий стол Windows с родными значками и обоями.
На нём отображаются только панели групп. Папки-дубликаты групп не создаются.
Страницы, стрелки переключения, формат .desk и захват скриншотов удалены.

ЯЗЫК
ПКМ по значку рядом с часами → Язык / Language → Русский или English.
Выбор сохраняется после перезапуска. Имена групп и расположение файлов не меняются.

ГДЕ ФАЙЛЫ
Основные группы — обычные папки в Проводнике:
  Документы\Группы Desk Bloom\Название группы
Папка «Группы Desk Bloom» закрепляется в быстром доступе Проводника.
Группа, созданная через ПКМ в «Загрузках» или другой папке, хранится там же.
Открыть содержимое: «⋯» на группе → «Открыть папку группы».
Двойной щелчок по значку Desk Bloom рядом с часами открывает папки групп.

УПРАВЛЕНИЕ
ПКМ по обычному рабочему столу → «Создать группу Desk Bloom».
ПКМ по пустому месту папки → «Создать группу Desk Bloom в этой папке».
В Windows 11 эти пункты могут быть в «Показать дополнительные параметры».
Также создание групп доступно через значок Desk Bloom рядом с часами.
Клик по заголовку группы раскрывает сетку файлов под ним.
Повторный клик сворачивает её. Перетаскивание заголовка перемещает панель.
Положение, цвет и открытое/закрытое состояние сохраняются автоматически.

Перетащите файлы и целые папки на группу либо нажмите «+ Файлы» / «+ Папка».
Файлы физически переносятся. При одинаковых названиях добавляется номер.
ПКМ по файлу или значку программы → «Добавить в группу Desk Bloom…».
Для установленной программы используйте существующий ярлык:
системные файлы Windows / Program Files должны оставаться на месте.
Двойной клик по файлу внутри группы открывает его обычной программой.
ПКМ по файлу внутри группы позволяет вернуть его на рабочий стол
или перенести в другую группу.

Меню «⋯» группы позволяет переименовать её вместе с настоящей папкой,
сменить цвет, выбрать другое расположение папки или убрать панель.
При удалении панели файлы остаются в своей папке.
Переименование папки в Проводнике подхватывается программой.
Ctrl + Alt + D — показать группы на рабочем столе.
Автозапуск включается и выключается через меню значка рядом с часами.

СОХРАНЕНИЕ
Настройки: Документы\DeskBloom\state.json, с резервной копией.
В каждой папке группы есть «Название.groups» с её настройками.
Двойной щелчок по .groups показывает или восстанавливает группу,
включая ранее убранную панель. Повторное открытие не создаёт дубликаты.
Это документ настроек, а не архив: для переноса сохраняйте всю папку группы.

После обновления все существующие группы доступны на одном рабочем столе.
Файлы прежних страниц возвращаются на рабочий стол без перезаписи совпадений.
Старые служебные папки сохраняются, чтобы не потерять пользовательские данные.
Ранее сохранённые скриншоты оставлены как обычные PNG:
  Документы\DeskBloom\Screenshots
Программа больше не следит за буфером обмена и не создаёт миниатюры снимков.

ИСХОДНИКИ
src\Core.cs — данные, обычные папки и формат .groups.
src\GroupsWindow.cs — панели, меню Windows, трей и импорт файлов.
src\GroupUi.cs — оформление и раскрывающиеся сетки.
src\ShellHelpers.cs — взаимодействие с рабочим столом и Проводником.
src\Migration.cs — однократное обновление старых данных с журналами.
src\Tests.cs — проверки переноса, восстановления и интерфейса.
src\Language.cs — английский и русский интерфейсы.
src\Demo.cs — демонстрационные примеры для документации.
Сборка: src\build-DeskBloom.ps1 (штатный компилятор .NET Framework).
Windows 10 / 11 с .NET Framework 4.x. Сеть не используется.


ОФОРМЛЕНИЕ 4.0
Меню «⋯» группы → «Оформление группы…».
Выберите цвет значка и кнопки из 30 вариантов, а фон — из отдельной палитры.
Выберите один из 15 значков или нажмите «Загрузить изображение…».
Свои изображения уменьшаются до 96 пикселей с сохранением пропорций.
Копия значка хранится в скрытой служебной папке .deskbloom внутри группы.
Эта папка не отображается среди файлов панели. Исходное изображение не перемещается.
Нажмите «Сохранить». Каждая группа имеет свои настройки. «Отмена» отменяет изменения.

Меню «⋯» → «Переименовать»: выделите слово или любую часть названия.
Выберите цвет из 30 вариантов, B (жирный), I (курсив), U (подчёркнутый).
«Сбросить форматирование» очищает оформление выделения.
Ctrl+B, Ctrl+I, Ctrl+U также работают в редакторе названия.
Название должно быть допустимым именем папки, длиной от 1 до 100 символов.
«Сохранить» переименовывает настоящую папку; стили сохраняются в .groups.
Для переноса группы вместе с её значком копируйте всю папку, включая скрытые файлы.

ПАМЯТЬ В 4.1
Программная отрисовка снижает расход памяти графическим драйвером.
Анимации сохранены, до 45 кадров/с. Свёрнутые группы освобождают содержимое.
Тесты и генератор примеров не входят в обычный EXE. Для них нужна сборка -Diagnostics.
